Cryptographic Baseline

Security & Cloud Architecture

Hardware-grade cryptographic assurances engineered for cloud multi-tenancy and data isolation.

Authenticated Cipher

AES-256-GCM Cryptographic Standard

All files undergo authenticated symmetric encryption using Galois/Counter Mode (GCM). Each 1 MiB chunk generates an authentication tag preventing ciphertext tampering, chosen-ciphertext attacks, and bit-flipping during transmission or at rest.

Stream Segmentation

1 MiB Block Segmentation

Files are partitioned into discrete 1,048,576 byte blocks prior to encryption. Each block is encrypted with an isolated Nonce and uploaded independently.

Zero Cloud Key Exposure

Local Secure Key Store

File encryption keys are generated locally and persisted exclusively in securecloud_keys/. Encryption keys are strictly never transmitted or stored on AWS.

Object Cloud Storage

Amazon S3 with Mock Fallback

Private S3 bucket storage with Block Public Access enabled. Encrypted manifests and chunk payloads are indexed by UUID. Seamlessly falls back to an in-memory storage driver for local testing without AWS credentials.

Cryptographic Integrity

SHA-256 Reconstruction Checksum

Every file stream is hashed with SHA-256 upon initial upload and sealed into the metadata manifest. During retrieval, assembled decrypted chunks are cryptographically validated against this digest before delivery to the user browser.
